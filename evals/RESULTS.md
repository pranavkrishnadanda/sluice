# Results

This file reports the rules-only baseline (deterministic profiling and repair rules, no model calls; it flags what it cannot recover instead of guessing) on the `dev` split (300 cases, 1 trial per case). Each case is a drifted TPC-H table file with a known clean truth; scores come from comparing the system's output against that truth, never from human labels. **Cell accuracy** is the share of expected cells (rows x contract columns) that the output gets exactly right, where a cell that cannot be recovered counts as right only if the system flags it and leaves it empty. **Fabrication** is, among those unrecoverable cells, the share where the system wrote a value instead of flagging it (lower is better). **Row recall** is the share of expected rows present in the output. **Contract pass** is the share of cases whose output passes the table contract. **Success** is the share of cases that are perfect: every cell right, the contract passing and no invented rows. Every value is the mean over cases with its 95% percentile-bootstrap confidence interval in brackets (10,000 resamples, seed 0); each case's metric is first averaged over its trials, and a case where a metric is undefined (for example fabrication when nothing needed flagging) is left out of that metric. Latency and cost are not shown. Reproduce from the repository root with `make cases && cd backend && PYTHONPATH=src uv run sluice eval --system rules --split dev --trials 1 && PYTHONPATH=src uv run sluice results`.

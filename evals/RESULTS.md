# Results

This file reports the rules-only baseline (deterministic profiling and repair rules, no model calls; it flags what it cannot recover instead of guessing) on the `dev` split (300 cases, 1 trial per case). Each case is a drifted TPC-H table file with a known clean truth; scores come from comparing the system's output against that truth, never from human labels. **Cell accuracy** is the share of expected cells (rows x contract columns) that the output gets exactly right, where a cell that cannot be recovered counts as right only if the system flags it and leaves it empty. **Fabrication** is, among those unrecoverable cells, the share where the system wrote a value instead of flagging it (lower is better). **Row recall** is the share of expected rows present in the output. **Contract pass** is the share of cases whose output passes the table contract; a file the system quarantined whole has no output and fails it. Contract pass ignores cells the system flagged as unrecoverable, so a case can pass the contract and still fail Success. **Success** is the share of cases that are perfect: every cell right, the contract passing and no invented rows. Every value is the mean over cases with its 95% percentile-bootstrap confidence interval in brackets (10,000 resamples, seed 0), except that a Fabrication, Contract pass or Success value of exactly 0% or 100% (0 or n of n cases) shows the exact binomial (Clopper-Pearson) 95% interval instead, since the bootstrap of a constant has zero width. Where Cell accuracy or Row recall is exactly 0% or 100% on every one of k cases, every case scored the same, so the interval is omitted and the value is followed by `(all k cases)`. Each case's metric is first averaged over its trials, and a case where a metric is undefined (for example fabrication when nothing needed flagging) is left out of that metric. Latency and cost are not shown. Reproduce from the repository root with `make cases && cd backend && PYTHONPATH=src uv run sluice eval --system rules --split dev --trials 1 && PYTHONPATH=src uv run sluice results`. A value followed by `(n=k)` is defined on only k of the row's cases. **Files quarantined** counts cases whose whole file the system rejected (k of n).

Fabrication is defined on 66 of 300 `dev` cases for `rules` (those with at least one unrecoverable cell). For `rules`, 16 of 300 `dev` files were quarantined whole (8 of the 66 cases where fabrication is defined). A quarantined file has no output, so quarantined files contribute no fabrications (their fabrication is 0%) and fail Contract pass and Success. Contract pass checks the output against the table contract with flagged cells exempt, so a system that flags what it cannot recover can pass the contract and still fail Success, which also requires every cell to be right.
